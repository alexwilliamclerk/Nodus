从一句话，到一个可打开的作品。

当前版本：v1.6.2。先用“免密钥体验”熟悉流程；真实生成需要连接自己的模型服务。

连接模型

  1. 打开左下角“模型连接”，进入连接设置。
  2. 选择服务商，填写 API Key。模型名称可留空使用该入口的默认模型。
  3. 点击“添加并验证”，等待明确的成功提示。验证会向服务商发起一次调用；失败时按提示检查密钥、余额或网络。

密钥保存在本机或仅当前会话中，不随账号同步到其他电脑。请勿把密钥放进聊天、截图或反馈报告。

制作、保存与打开

  1. 输入具体目标，例如“做一个离线飞机大战游戏，方向键移动、空格射击”。Enter 发送，Shift+Enter 换行。
  2. 选择制作方向，确认后选择本地保存目录。需要放在桌面时，在文件夹选择器中选择桌面。
  3. 完成后使用“在浏览器打开作品”运行网页作品，或“打开目录”查看文件。已有作品可通过“导出作品”保存到其他位置。

“允许接收方”只批准联网发送，不代表文件已经保存。预览、打开和导出入口在生成了作品版本后显示。生成结果仍需你检查是否符合实际需求。

本机保存与跨设备同步

“已保存”表示本机保存。打开侧栏“账号与同步”，注册或登录后核对同步范围，再使用“立即同步”。另一台电脑登录同一账号，按界面说明同步或恢复。同步当前需要主动操作，不等同于多人实时协作。模型密钥、设备设置及执行授权留在各自电脑。

可选功能

任务预算限制模型用量，并不是预付金额，也不保证任务完成。“更多工具”中的建议追踪适用于日后复查曾采纳的依据；普通对话无需使用。目前没有面向普通用户的一键插件安装器，“扩展与集成”会先解释可用能力。

独立图像生成

在输入区点击“图像生成”，填写独立生图服务的 HTTPS 地址、模型名称和 API Key。当前支持 OpenAI Images generations 兼容接口与 base64 图片返回。保存不会发起付费验证；启用后，Agent 每次制作最多请求一张图片，费用不包含在文字 token 预算内。生成文件保存在作品目录，网页可以引用这些图片。现有 PPT 编译协议仍不支持图片嵌入。

v1.6.2 更新

  • 新增独立图像 API 入口，与文字模型连接分开；支持加密记住连接。
  • 排除其他系统与架构的原生二进制，缩小安装包。
  • 制作请求进入作品流程，支持目录选择、文件导出和浏览器打开。
  • 连接、外观及其他设置分开；增强账号、保存状态和免密钥体验入口。
  • 简化预算、权限及扩展说明，新增后台任务结束提示和运行版本诊断。
  • 更新检查使用官方服务器，并保留受校验保护的备用下载路径。
  • 生成时的密钥、余额等错误显示简短处理提示。

macOS 安装包未签名或公证，Windows 安装包未做代码签名。系统可能提示无法验证开发者。请只使用官网来源，并核对 SHA-256 校验值。v1.6.0 起闭源发行，旧版本及第三方组件许可继续有效。
