从一句话，到一个可打开的作品。

当前版本：v1.7.0。先用“免密钥体验”熟悉流程；真实生成需要连接自己的模型服务。

连接模型

  1. 打开左下角“模型连接”，进入连接设置。
  2. 选择服务商，填写 API Key。模型名称可留空使用该入口的默认模型。
  3. 点击“添加并验证”，等待明确的成功提示。验证会向服务商发起一次调用；失败时按提示检查密钥、余额或网络。

密钥默认加密保存在本机，重启和更新后自动恢复；可取消保存，仅在当前会话使用。密钥不随账号同步到其他电脑。请勿把密钥放进聊天、截图或反馈报告。

制作、保存与打开

  1. 输入具体目标，例如“做一个离线飞机大战游戏，方向键移动、空格射击”。Enter 发送，Shift+Enter 换行。
  2. 选择制作方向，确认后选择本地保存目录。需要放在桌面时，在文件夹选择器中选择桌面。
  3. 完成后使用“在浏览器打开作品”运行网页作品，或“打开目录”查看文件。已有作品可通过“导出作品”保存到其他位置。

“允许接收方”只批准联网发送，不代表文件已经保存。预览、打开和导出入口在生成了作品版本后显示。生成结果仍需你检查是否符合实际需求。

本机保存与跨设备同步

“已保存”表示本机保存。打开侧栏“账号与同步”，注册或登录后核对同步范围，再使用“立即同步”。另一台电脑登录同一账号，按界面说明同步或恢复。同步当前需要主动操作，不等同于多人实时协作。模型密钥、设备设置及执行授权留在各自电脑。

可选功能

任务预算限制模型用量，并不是预付金额，也不保证任务完成。“更多工具”中的建议追踪适用于日后复查曾采纳的依据；普通对话无需使用。目前没有面向普通用户的一键插件安装器，“扩展与集成”会先解释可用能力。

图片、花体标题与网络素材

在输入区点击“图像生成”，独立配置 MiniMax 国内／国际或 OpenAI Images 兼容服务。Agent 可在设定的张数上限内生成多张图片，并按页面需要选择比例。图片可以实际嵌入 PPT；纵向图片保持原始比例，生成记录保留实际提示词。图片调用单独计费，保存连接不产生生图费用。

需要艺术标题时，可说明“封面使用毛笔字／行草／金色／描边标题”。Agent 可在本机生成透明标题字图，正文保持可编辑。字图不是 PowerPoint 原生字体文本，文字修改后需要重新渲染。

Agent 可搜索 Wikimedia Commons 并下载有明确许可的图片，保存署名、许可证和来源；通用网页查询使用已配置的搜索服务。搜索描述不等于图像已核实，素材使用仍应结合具体来源说明。

可添加 PPTX 作为文字与版式结构参考；当前不保证任意母版的完整复刻。制作过程包含逐页设计、图文与来源检查，最终效果仍需视觉验收。

网站内容与页面检查

制作前，Agent 会规划访客、首要行动、来源、视觉方向和页面区块。生成后在隔离浏览器中检查桌面与手机页面，报告横向溢出、坏图、失效锚点、空链接和缺少名称的按钮，检查占位内容和缺失区块。修改后的文件需重新检查。

检查截图与报告保存在作品的 website-review 目录。支持视觉的模型可进一步查看截图；不支持视觉的模型只能依据结构和布局报告调整。检查通过不保证审美质量、事实正确或全部交互可用。
