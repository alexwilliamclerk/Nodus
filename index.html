Before you begin

开始之前。

Nodus 是一个模型吗？＋

Nodus 是连接你与模型的桌面工作台。你可以配置自己的模型 API 连接，用它规划、制作和审阅任务。模型能力与调用费用取决于你接入的服务。

我的资料会发送到哪里？＋

需要模型处理的内容会发送到你配置的模型服务。Nodus 提供外发审阅与人工脱敏，你可以查看请求并移除选中的信息。使用前请了解对应服务商的数据政策。

安全测试通过，就代表 Agent 绝对安全吗？＋

不代表。测试结果只描述相应任务、材料与模型下观察到的行为。Nodus 分别展示实际结果、权限拦截和原任务完成情况，帮助你判断安全性与可用性。

从哪里了解使用方式与当前能力？＋

阅读 使用手册 与 发行说明。源码中的新功能可能尚未进入当前安装包，具体以对应版本为准。
