# Launch material / 发布素材

These are editable drafts, not published posts. The no-key demo is included in v1.5.2; the website also provides a browser walkthrough. Do not describe the local preview URL as a public site.

## English post draft

**Nodus: inspect agent actions and try scripted safety examples without an API key**

I built Nodus for developers and creators who want to inspect what an AI task is allowed to do, what gets sent to a model, and what becomes memory.

The source version includes three no-key, offline walkthroughs: prompt injection, reviewable and revocable memory, and task budgets with context compression. The walkthrough outcomes are scripted teaching examples. You can create a separate task from their fictional inputs and manually run it with your own model.

The real workspace provides task-scoped permissions, outgoing-request review, copied-task safety checks and reviewed memory. A blocked action and a completed task are assessed separately. I am looking for feedback on whether the first-run explanation is clear and where setup gets in the way.

Source and instructions: https://github.com/alexwilliamclerk/Nodus

## 中文发布草稿

**给 AI Agent 设定权限以后，原来的任务还能不能完成？**

我做了 Nodus，希望让个人开发者能够检查 Agent 的操作权限、发给模型的内容，以及被保存下来的记忆。

源码版本新增三个无需 API Key 的离线演示：提示注入、记忆审阅与撤销、预算与上下文压缩。演示结果是明确标注的虚构情景，不是模型性能证明；可以把示例输入创建成独立任务，再用自己的模型手动运行。

我想先找愿意试用的开发者，看看首次使用能不能理解、模型接入是否顺畅，以及哪些功能值得再次使用。项目地址：https://github.com/alexwilliamclerk/Nodus

## First ten users / 首批试用

Invite people individually only with permission and where community rules allow it. Ask them to try one case, explain the value in their own words, and report where they stopped. Do not request credentials or private task data. A useful issue includes OS, source version, case, observed behavior and a redacted error if relevant.

发布时说明作者身份，按社区规则提供可试用入口。不要群发、互刷 Star 或以功能使用权换取 Star。
