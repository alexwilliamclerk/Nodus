# Nodus v1.2.0

设置中新增外观主题：浅色、深色、跟随系统。切换后界面与原生菜单立即更新，选择在重启后保留。生成的网站预览保留作品自己的配色。

## 安装

- macOS Apple Silicon：下载 `Nodus-mac-arm64.dmg`，打开并将 Nodus 拖入 Applications。
- Windows x64：下载 `Nodus-windows-x64.exe`，运行安装向导。
- Linux x64：下载 `Nodus-linux-x64.AppImage`，赋予执行权限后运行。
- `SHA256SUMS.txt` 提供三个安装包的 SHA-256 校验值。

安装包内置 Electron 与 Pi SDK；使用模型需要自行配置有效凭据。Linux AppImage 可能需要发行版提供 FUSE 运行库。

## 验证与限制

主题切换、跟随系统及重启恢复在隔离数据目录的 macOS 桌面测试中通过；87 项自动化测试通过。GitHub Actions 分别重新构建三平台安装包，并核对包内应用文件。Windows 与 Linux 干净系统实机安装仍待验证。安装包尚无正式开发者签名，macOS 尚未公证。
