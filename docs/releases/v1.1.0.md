# Nodus v1.1.0

从一个想法，到一份真正可交付的作品。

Nodus 将需求澄清、Agent 制作、作品预览、用户反馈和版本管理放在同一个桌面工作空间。

## 本版功能

- 默认 `/plan` 先规划、确认后制作；`/goat` 在授权范围内自主执行，每次提交最多 3 次制作尝试。
- 可编辑任务要求、来源与历史记录，以及引用实际文件片段的模型辅助审查。
- 网站、Markdown 报告、PPTX、Python 工程和描述统计分析。
- 本地目录交付、版本恢复、真实文件导出和不含应用凭据的任务备份。
- 多模型连接、原生文件菜单、展开预览与可配置的中途预览节奏。

## 安装

- **macOS Apple Silicon**：下载 `Nodus-mac-arm64.dmg`，打开并将 Nodus 拖入 Applications。
- **Windows x64**：下载 `Nodus-windows-x64.exe`，运行安装向导。
- `SHA256SUMS.txt` 包含安装包的 SHA-256 校验值。

安装包内置 Electron 和 Pi SDK；调用模型需要自己的服务商凭据。Python 检查与数据分析需要本机 Python 3。

## 验证与限制

当前源码的 87 项本地自动化测试通过。GitHub Actions 对本次提交重新执行检查并构建安装包；构建日志可在 Actions 查看。模拟模型测试不代表真实模型端到端效果已验证。

安装包没有正式开发者签名或 macOS 公证，Windows 干净系统实机验收尚未完成。不提供 Intel Mac、Windows ARM 或 Linux 预构建包。

报告不做联网事实核实；Python 不自动执行生成代码；数据分析限描述统计。用户材料会发送到所选模型服务。
