# Nodus v1.4.1

Conversation history keeps the landscape background visible while restoring distinct, readable bubbles for the user's messages and Nodus replies in all four landscape themes.

After a request is submitted, a compact animated **Thinking…** bubble appears immediately, with the current activity beneath it. It switches to streamed reply text as soon as text arrives and disappears on completion, cancellation, or failure. The indicator is available in Chinese and English and respects reduced-motion settings.

## Downloads

- macOS Apple Silicon: `Nodus-v1.4.1-macOS-arm64.dmg`
- Windows x64: `Nodus-v1.4.1-Windows-x64.exe`
- Linux x64: `Nodus-v1.4.1-Linux-x86_64.AppImage`
- Linux one-line installer: `Nodus-v1.4.1-Linux-install.sh`

```bash
curl -fsSL https://github.com/alexwilliamclerk/Nodus/releases/download/v1.4.1/Nodus-v1.4.1-Linux-install.sh | bash
```

The release also includes stable compatibility filenames, Windows/Linux update metadata, and `SHA256SUMS.txt`. macOS updates open this release page for a manual DMG download.

**Windows installation note:** The EXE is not digitally signed. Windows may warn about or block an unfamiliar unsigned app, especially when Smart App Control is enabled. Verify the download against `SHA256SUMS.txt` before running it. This release does not resolve that signing limitation; trusted code signing or Microsoft Store distribution is required for a durable public-installation solution. The build workflow tests silent installation, upgrade and removal, but does not prove that double-click installation succeeds on every end-user PC.

macOS packages are unsigned and not notarized.
