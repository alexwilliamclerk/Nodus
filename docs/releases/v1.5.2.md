# Nodus v1.5.2

Chat is easier to read and connections are easier to confirm. This release also adds an offline demo for trying Nodus before entering model credentials.

## Chat and connection feedback

- Saved messages and streaming replies render Markdown headings, emphasis, lists, quotations, code and tables. Raw HTML is escaped; images do not load automatically.
- Ordinary answers default to short, direct prose; complex questions and explicit requests for detail can still receive longer explanations. This is a prompting change, not a measured guarantee of answer length or quality.
- Simple current-model questions report the configured provider and model ID. This identifies the client connection, not the provider's internal routing or model architecture.
- Connection verification shows waiting, failure or persistent success feedback with model details and a Start chatting action.
- Short user messages retain a natural width. Delete and advice actions appear on hover or keyboard focus; touch interfaces keep them visible. Scenic backgrounds are softened.

## Budget panel and no-key demo

The budget panel uses aligned fields, three overview cards, responsive pricing fields and folded explanations. The allocation, checking allowance, usage accounting and pricing behavior remain the same.

Open **Try without a key** for three bilingual scripted examples: prompt injection, reviewed/revocable memory, and budgets with context compression. Create a separate trial with fictional inputs, review permissions, connect a model and submit manually. Demo outcomes and approvals are never imported into real trials. The demo and recording are teaching examples, not live model evaluations or evidence of safety or savings.

## Downloads and installation

- macOS Apple Silicon: `Nodus-v1.5.2-macOS-arm64.dmg`
- Windows x64: `Nodus-v1.5.2-Windows-x64.exe`
- Linux x86_64: `Nodus-v1.5.2-Linux-x86_64.AppImage`

Install over the previous application to keep local tasks. Installers are not developer-signed/notarized; operating systems may show warnings or block installation. The release includes checksums and compatibility aliases.

## Validation

257 local automated tests passed. Scripted desktop checks cover Markdown history/streaming, connection waiting/failure/success, a short user bubble, and the budget workflow. Connection fixtures do not make real provider calls. Cross-platform build and package checks run before publication.
