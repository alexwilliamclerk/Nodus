# Nodus v1.3.2

Four new landscape themes are available in Settings: Lavender Dawn, Moonlit Peaks, Peach Mist, and Bamboo Pavilion. Each includes coordinated text, sidebar and control colors, an image preview, Chinese/English labels, and a selection that persists across restarts. Light, Dark and Follow system remain available.

You can now delete individual chat questions together with their answers, removing them from future chat context. Current and previously answered decision questions can also be deleted; dependent choices are invalidated and execution requires confirmation again.

## Downloads

- macOS Apple Silicon: `Nodus-v1.3.2-macOS-arm64.dmg`
- Windows x64: `Nodus-v1.3.2-Windows-x64.exe`
- Linux x64: `Nodus-v1.3.2-Linux-x86_64.AppImage`
- Linux installer script: `Nodus-v1.3.2-Linux-install.sh`

Windows and Linux update metadata and stable compatibility filenames are included. SHA256SUMS.txt contains download checksums. macOS updates open this release page for manual download and Finder replacement; packages remain unsigned.

The release workflow checks packaged source and assets and tests Windows upgrade/uninstallation with user data retention. Linux desktop behavior and installation on all end-user configurations are not exhaustively tested.
