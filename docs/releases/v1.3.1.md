# Nodus v1.3.1

本版允许在未设定产物类型时直接聊天，并可随时手动识别产物类型。新增基础 Word、Excel 和通用源码交付，支持 OpenAI 与 Anthropic API 连接，以及可选的联网搜索服务。网页修订会检查站内跳转目标并保护未选修改范围的交互入口；常规修改可以更早确认并查看新版本。

设置中的更新流程保留版本检查和安装包校验。Windows NSIS 与 Linux AppImage 安装版可在确认后由应用安装已下载的更新并重启；若自动更新元数据不可用，则打开安装器或定位 AppImage。Linux 更新时可选择删除旧 AppImage，或先备份旧程序文件。macOS 更新按钮会打开对应版本的 GitHub 发布页，由用户下载 DMG，并在 Finder 中决定是否替换旧 Nodus.app。三个平台都只处理程序文件，任务、作品与连接数据保留。

## 安装包

- macOS Apple Silicon：`Nodus-v1.3.1-macOS-arm64.dmg`
- Windows x64：`Nodus-v1.3.1-Windows-x64.exe`
- Linux x64：`Nodus-v1.3.1-Linux-x86_64.AppImage`
- Windows 与 Linux 自动更新元数据：`latest.yml`、`latest-linux.yml`
- 为兼容旧版更新器和固定下载链接，还提供三个内容相同的旧文件名；`SHA256SUMS.txt` 列出安装包校验值。

## 验证边界

自动化检查覆盖版本比较、元数据与安装包匹配、SHA-256 校验、失败时保留旧版、更新确认和修订流程。应用内自动安装在 Windows 与 Linux 打包环境执行；macOS 全自动替换仍需 Apple Developer ID 签名。各平台实际安装与升级结果以发布工作流和目标系统验收为准。
