# Nodus v1.3.0

设置中新增“检查更新”：读取 Nodus 官方 GitHub Releases，下载本平台安装包并核对 SHA-256。下载成功后，macOS 和 Windows 可以打开安装包；Linux 可以定位已下载的 AppImage。当前版本已是最新时，也可以重新下载安装包；如果损坏的是 Windows 卸载程序，请先按下方修复说明将损坏文件移出安装目录。更新操作由用户主动触发，不会在后台自动替换程序。

Windows 已安装版的设置中新增“卸载应用…”入口，启动系统卸载程序前会再次确认。若本机 `Uninstall Nodus.exe` 报 NSIS 完整性错误，请按 [修复说明](../windows-uninstall.zh-CN.md)处理：保留损坏文件的备份，将其移出安装目录，使用经过校验的安装包重装到原目录，然后正常卸载。不要跳过完整性检查。

## 安装包

- macOS Apple Silicon：`Nodus-mac-arm64.dmg`
- Windows x64：`Nodus-windows-x64.exe`
- Linux x64：`Nodus-linux-x64.AppImage`
- `SHA256SUMS.txt`：三个安装包的 SHA-256 校验值

## 验证与限制

更新服务通过版本比较、平台匹配、下载完整性及错误文件清理测试；更新设置交互使用模拟响应完成桌面检查。发布工作流检查三平台包内应用文件，并在干净 Windows 环境安装、检查系统卸载入口、运行卸载程序。另有隔离测试验证 v1.2.0 卸载程序损坏后的恢复方法。这些测试不能证明每台用户电脑都能卸载成功。

当前安装包尚未正式签名，macOS 未公证。Windows SmartScreen 的“未知应用”警告与 NSIS 文件完整性错误是不同情况；下载时请确认来源及校验值。
