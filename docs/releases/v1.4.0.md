# Nodus v1.4.0

## Adopt and track advice

Use **Adopt and track** beside an assistant reply to save a recommendation, the reasons you adopted it, and its public HTTPS sources. Open **Advice tracking** in the sidebar to check it, edit the reasons, pause or resume tracking, mark alerts as read, find alternative sources, or delete the watch.

Checks compare public-source evidence with your reasons and distinguish changed conditions, possible errors in the original recommendation, and insufficient evidence. Relevant alerts include source links and quotations. Failed checks preserve earlier alerts. Watches and check history survive restarts and are included in backups.

Daily automatic checks are opt-in and run only while Nodus is open. Reviews use the configured model and may incur API costs. AI assessments need human verification. Login-required or JavaScript-rendered pages may remain unverified; source excerpts are limited in length. Real public-page reading and deterministic model fixtures were tested; live model judgment accuracy has not been established.

## Appearance

Removed the remaining tinted transcript container and glass effects. Conversation history sits directly on the landscape background. The four landscape themes and Chinese/English interface remain available.

## Downloads

- macOS Apple Silicon: `Nodus-v1.4.0-macOS-arm64.dmg`
- Windows x64: `Nodus-v1.4.0-Windows-x64.exe`
- Linux x64: `Nodus-v1.4.0-Linux-x86_64.AppImage`
- Linux one-line installer script: `Nodus-v1.4.0-Linux-install.sh`

```bash
curl -fsSL https://github.com/alexwilliamclerk/Nodus/releases/download/v1.4.0/Nodus-v1.4.0-Linux-install.sh | bash
```

The Linux script installs the latest published release. Stable download aliases, Windows/Linux update metadata and SHA256SUMS.txt are included. macOS updates open GitHub for manual DMG download and Finder replacement. macOS packages are unsigned and not notarized.

The release workflow verifies packaged application files and update metadata, and tests Windows installation, upgrade from the previous published release, uninstallation and user-data retention. This does not cover every end-user machine configuration.
