# Nodus v1.5.1 — Task budgets and reviewable context compression

Two new controls for everyday agent work: decide how computation is allocated, and review which earlier context is carried forward.

## Task budget mode

Open **Task budget** in the task header. Ask the current model to decompose the task, review or adjust complexity estimates, then approve token allowances for planning, execution steps and checking. Execution cannot borrow the checking allowance. Both file-producing tasks and standalone answers follow the reviewed steps.

The panel shows used/reserved tokens, remaining allowance and cost estimates based on your USD rates. Usage survives restart and replanning. Unknown usage retains its requested cap; missing prices are not treated as free calls. Cancellation, exhausted budgets and truncated checks stop the operation, preserving unfinished files.

Limits cover generation tokens, including reasoning counted as output by the provider. Internal thinking is not capped separately; input usage is outside the generation allowance. Cost estimates are not invoices or hard dollar limits.

## Reviewable context compression

Open **Safety & permissions → Reviewable context compression**. Select earlier replies, text materials or readable version context. Draft a summary manually or with the current model, inspect exact source quotations and retained details, then explicitly approve it.

User messages, recent turns, current requirements and permissions remain separate. Editing requires renewed review; revocation restores current originals. Changed or deleted source records invalidate old summaries. Original records and reviewed snapshots are retained in private backups. Outgoing-request review sees the actual compressed body; compression does not declassify sensitive sources.

The preview measures characters, not guaranteed token or cost savings. It does not automatically compact the current tool loop. Saved safety assessments keep their own original input copies.

## 中文摘要

- **任务预算模式**：先拆解问题，再按复杂度为规划、执行子任务和检查分配生成 token；显示花费估算与剩余额度，保留检查额度及历史用量。
- **可审阅的上下文压缩**：选择旧资料，对照原文审阅摘要，确认后才用于后续调用；支持逐字保留未决事项、编辑后重审、撤销和来源变化失效。
- 两项功能继续遵守任务要求与已有权限边界，均无需重新训练模型。

## Verification and installation notes

Local development validation passed 252 automated tests plus scripted desktop scenarios using real SDK encoding/decoding and synthetic provider replies. These establish functional behavior, not real-model summary accuracy, efficiency gains or complete prompt-injection resistance. No paid model calls were used for this feature validation.

Installers are not formally developer-signed/notarized. Windows may warn about or block an unsigned EXE. Verify downloaded files against the checksums; automated installation/upgrade/removal checks do not replace interactive testing on every machine.
