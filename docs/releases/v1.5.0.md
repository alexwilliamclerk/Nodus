# Nodus v1.5.0 — Review agent actions, test your tasks, control memory

Nodus is an AI agent desktop workspace for independent developers and creators. This release brings practical safety controls into the same workflow as planning, producing and reviewing real deliverables.

## Highlights

- **Permissions before actions:** task-scoped file access, recipient approvals, natural-language policy drafts and revocable grants.
- **Safety checks using your own tasks:** isolated copies with synthetic leakage, protected-file modification and goal-override probes. Reuse saved inputs across models, with unsafe effects, policy blocks and task utility reported separately.
- **Review actual outgoing requests:** opt-in disclosure review and selected field/value removal at the model transport boundary.
- **Inspect and recover:** source/action evidence, selected-material isolation and clean retries that preserve the original work.
- **Reviewable, revocable memory:** provenance and task/project scopes, candidate-only extraction from external material, explicit review, edits requiring reapproval, revocation and deletion. Memory never automatically enters the confirmed requirement ledger.

v1.5.0 的重点是让 Agent 的行动和记忆更可控：执行前核对权限、用自己的任务做安全体检、查看实际外发信息、隔离可疑材料后重试，以及逐条审阅和撤销项目记忆。入口位于任务右上角的“安全与授权”。

## Verification and limits

Local development validation passed 220 automated tests and scripted desktop checks using the real SDK and file tools. These are functional checks, not a real-model safety ranking. A bounded earlier live-model pilot also found baseline resistance and a clean-task interruption; see [the evaluation report](https://github.com/alexwilliamclerk/Nodus/blob/main/docs/safety-evaluation.md).

Controls cover supported Nodus operations, not arbitrary OS activity or exported files run elsewhere. Revocation cannot recall already transmitted content or erase existing outputs. External observations remain unverified even after human review. Model calls use your configured provider and may incur fees.

Installers are not formally developer-signed/notarized. Windows can show SmartScreen or Smart App Control warnings. Automated packaging and silent-install checks do not replace interactive testing on every user's computer. Verify downloads against the checksums in this release.
